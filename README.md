# 🎬🔊 폴리 아티스트 (Foley Artist)

초등학생(1~3학년 포함)이 **영상을 보면서 소리를 녹음하고, 그 소리를 영상에 입히는** 폴리아티스트 활동용 웹앱입니다.
설치나 빌드 없이 브라우저에서 바로 동작합니다.

## 화면 구성

```
┌──────────────────────────────────────┬───────────────┐
│  🎬 영상 미리보기 (좌측 상단)          │ 🎤 소리 녹음   │
│  ⏮ ▶ 0:00 / 0:12   ☑ 영상 원래 소리  │  큰 녹음 버튼  │
├──────────────────────────────────────┴───────────────┤
│  🎞 트랙 (하단)                                        │
│  시간  │ 0:00   0:01   0:02   0:03 ...                 │
│  🎬 영상 │ ▣▣▣▣▣▣▣▣▣▣ (장면 미리보기)                  │
│  🎤 소리 1 │     ████ 녹음 1                           │
│  🥁 소리 2 │            ██████ 녹음 2                  │
│  ➕ 트랙 추가                                          │
└──────────────────────────────────────────────────────┘
```

## 아이들이 쓰는 방법

1. **🎬 영상 가져오기** 버튼을 누르거나 영상 파일을 화면에 끌어다 놓아요.
2. 큰 **🎤 버튼**을 누르면 3·2·1 카운트다운 뒤에 영상이 재생되면서 녹음이 시작돼요.
3. 영상을 보며 소리를 내고, 다시 **⏹ 버튼**을 누르면 녹음이 끝나요. 녹음한 소리가 트랙에 나타나요.
4. **▶ 재생**으로 영상과 소리를 함께 들어 봐요.
5. 소리 블록을 **끌어서** 시간을 맞추거나 다른 트랙으로 옮길 수 있어요.
6. **💾 작품 저장하기**를 누르면 소리가 입혀진 영상 파일이 내려받아져요.

## 기능

- 영상 불러오기(파일 선택 / 끌어다 놓기), 장면 썸네일 타임라인
- 트랙 추가·삭제, 트랙 이름/아이콘(이모지) 바꾸기, 트랙 소리 끄기
- 카운트다운 후 녹음, 녹음 중 마이크 소리 크기 표시
- 녹음 클립 파형 표시, 끌어서 시간 조절, 트랙 간 이동, 삭제
- 영상 원래 소리 켜기/끄기
- 영상 + 모든 트랙을 합쳐 **WebM(또는 MP4)** 파일로 내보내기
- 브라우저(IndexedDB)에 **자동 저장** → 다시 열면 "이어서 할까요?"
- 트랙 그림(이모지)은 그림 고르기 창에서 직접 선택
- 📱 QR 버튼: 현재 주소의 QR을 띄워 학생 태블릿으로 바로 접속
- 📤 선생님께 보내기 + 발표 화면(`present.html`): Firebase로 작품을 모아 교실 화면에서 바로 재생
- 태블릿 대응: 뒤로 가기·당겨서 새로고침·두 번 탭 확대 막기, 화면 꺼짐 방지, 홈 화면에 추가(PWA 매니페스트)
- 키보드: `Space` 재생/멈춤, `Delete` 고른 소리 지우기, `←/→` 0.1초 이동(Shift: 1초), `Home` 처음으로

## 선생님께 보내기 · 발표 화면 (Firebase)

학생이 **📤 선생님께 보내기**를 누르면 작품 영상이 Firebase에 올라가고,
선생님이 `present.html`(발표 화면)을 열면 학생 작품 목록이 실시간으로 나타나 바로 재생할 수 있습니다.

### 흐름
- 선생님: 발표 화면 → 구글 로그인 → 처음이면 교실 코드가 자동으로 만들어지고 **학생 접속 QR**이 뜸 → 교실 화면에 QR 띄우기
- 학생: QR을 찍으면 교실 코드가 담긴 주소로 접속 → 작품 완성 → 보내기 → 이름(또는 번호)만 적으면 끝
- 선생님: 발표 화면에 작품이 도착한 순서대로 번호가 붙어 나타남 → 누르면 전체 화면 재생, ◀ ▶로 다음 학생
- 수업이 끝나면 **전체 지우기**로 정리 (학생 목소리가 남지 않도록)

### 한 번만 하는 설정
1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 열기(기존 프로젝트 사용 가능)
2. **Authentication → Sign-in method**에서 `익명`과 `Google`을 켜기
   - **Settings → 승인된 도메인**에 앱 주소 도메인(예: `pnoni2080.github.io`) 추가
3. **Firestore Database** 만들기(프로덕션 모드) → **규칙** 탭에 `firestore.rules` 내용 붙여 넣기
4. **Storage** 만들기 → **규칙** 탭에 `storage.rules` 내용 붙여 넣기
   - 2024년 10월 이후 새 프로젝트는 Storage에 Blaze(종량제) 플랜이 필요합니다. 무료 한도 안에서는 비용이 0원입니다.
5. **프로젝트 설정 → 내 앱 → 웹 앱(</>) 추가** 후 `firebaseConfig` 값을 `js/firebase-config.js`에 붙여 넣기
6. 푸시(배포)하면 학생 화면에 **선생님께 보내기** 버튼이 나타나고 발표 화면이 켜집니다

설정이 비어 있으면 보내기 버튼과 발표 화면은 숨겨지고, 녹음·저장 기능은 그대로 동작합니다.

### 권한 규칙 요약
- 학생은 익명 로그인으로 **올리기만** 할 수 있고, 지울 수는 없습니다.
- 교실 만들기와 작품 삭제는 **구글로 로그인한 선생님**만 할 수 있습니다.
- 작품 1개당 300MB 제한. 학생 이름은 20자까지만 저장됩니다.

### 로컬 에뮬레이터로 시험하기
```bash
npm i -g firebase-tools
firebase emulators:start --project demo-foley   # firebase.json의 에뮬레이터 설정 사용
# js/firebase-config.js 에서 FOLEY_USE_EMULATOR = true 로 바꾸고 아무 설정값이나 넣어 테스트
```

## 실행 방법

마이크는 **https** 또는 **localhost** 에서만 사용할 수 있어요.

- 가장 쉬운 방법: GitHub Pages 자동 배포. 저장소를 **Public**으로 바꾸면 푸시할 때마다
  `.github/workflows/pages.yml`이 https://pnoni2080.github.io/Foley-artist/ 에 배포합니다.
  (비공개 저장소의 Pages는 GitHub 유료 플랜에서만 됩니다.)
- 로컬에서 테스트:
  ```bash
  python3 -m http.server 8000   # 또는 npx serve .
  # 브라우저에서 http://localhost:8000 열기
  ```

## 권장 브라우저

Chrome / Edge 최신 버전(크롬북 포함)을 권장합니다. 녹음·내보내기는 `MediaRecorder`를 사용하며, Safari는 MP4로 내보냅니다.
녹음 중에는 마이크에 스피커 소리가 섞이지 않도록 영상 소리와 다른 트랙 소리를 잠시 끕니다.

## 파일 구성

```
index.html            학생용 화면 구조
present.html          선생님용 발표 화면
js/present.js         발표 화면 로직
js/cloud.js           Firebase 연결(교실·작품 올리기·목록)
js/firebase-config.js Firebase 설정(선생님이 채움)
firestore.rules       Firestore 보안 규칙
storage.rules         Storage 보안 규칙
firebase.json         에뮬레이터 설정
js/vendor/firebase/   Firebase SDK(compat) 동봉
css/present.css       발표 화면 스타일
css/style.css         스타일(어린이용 큰 버튼, 트랙 레이아웃)
js/app.js             재생·녹음·타임라인·내보내기·자동 저장 로직
js/vendor/qrcode.js   QR 생성 라이브러리 (qrcode-generator, MIT)
manifest.webmanifest  홈 화면에 추가용 앱 정보
icons/                앱 아이콘
```

## 태블릿에서 쓸 때

- 크롬(안드로이드) 또는 사파리(iPad)에서 열고 **홈 화면에 추가**하면 주소창 없이 전체 화면으로 열립니다.
- 뒤로 가기를 눌러도 앱이 닫히지 않고 안내만 뜹니다. 작업은 자동 저장됩니다.
- 교사용: 상단 📱 QR 버튼으로 접속 QR을 띄워 교실 화면에 보여 주세요.
